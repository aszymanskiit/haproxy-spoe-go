# Security Policy

## Supported versions

Security fixes are applied to the latest commit on the default branch of this maintained fork:

- Repository: https://github.com/aszymanskiit/haproxy-spoe-go

Older tags or historical commits may not receive backports unless a maintainer explicitly decides otherwise.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Prefer one of the following private channels:

1. **GitHub Security Advisories** (preferred when available for this repository): use *Security* → *Report a vulnerability* on https://github.com/aszymanskiit/haproxy-spoe-go.
2. If advisories are unavailable, contact the repository maintainers privately through GitHub (for example a private maintainer discussion or direct message to a listed maintainer).

Include as much detail as you can:

- affected version or commit SHA
- description of the issue and impact
- reproduction steps or a proof of concept
- whether a fix is already known

## Response process

Maintainers will acknowledge valid reports when possible and coordinate a fix and disclosure. Response times vary depending on severity and maintainer availability; please do not expect a guaranteed SLA.

Please give maintainers reasonable time to investigate and publish a fix before any public disclosure.
